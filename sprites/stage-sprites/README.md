# Stage Sprite Pack

Extracted from the approved stage concept sheet.

## Folders / naming
- `barnyard_*` — Barnyard Brawl
- `fridge_*` — Fridge Frenzy
- `meadow_*` — Sky-High Meadow

All PNG files use transparent backgrounds and are intended as visual assets only.
Gameplay collision geometry should remain defined separately in shared/server stage data.

Copy this folder into:
`client/public/assets/stages/sprites/`

Use `manifest.json` as the asset lookup reference.
